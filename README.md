# 🎧 Spotify Playlist Matcher

A full-stack web app that analyzes Spotify tracks and generates playlist recommendations based on track data like popularity, name, and metadata.

---

## 🚀 Features

- 🎵 Paste a Spotify track link to analyze a song
- 🔍 Extracts track information using Spotify Web API
- 🧠 Generates dynamic playlist recommendations
- 🔐 Simple authentication system (signup / login)
- ⚡ Real-time UI updates with React state management
- 🌐 Full-stack setup (React + Express backend)

---

## 🛠️ Tech Stack

### Frontend

- React
- React Router
- Fetch API
- CSS Modules / custom styling

### Backend

- Node.js
- Express
- dotenv
- CORS

### External API

- Spotify Web API
